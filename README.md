## ✨ 核心特性

- 🚀 **零额外硬盘空间消耗**：利用 Android 底层 `ext4` 文件系统的**硬链接（Hard Link）**特性，所有区服指向相同物理磁盘块，每增加一个服节省约 29GB 电脑磁盘！
- ⚡ **秒级极速就绪**：整个资产库链接过程通常在 **1 ~ 3 秒内完成**，告别数小时的网络下载折磨。
- 🔍 **全自动智能探测**：
  - 自动扫描并定位本地 MuMu 模拟器安装路径与 ADB 通信端口（`16384`、`7555`、`5555` 等）；
  - 自动扫描模拟器内已安装的全部碧蓝航线客户端；
  - 自动识别哪个服已包含 29GB 完整数据作为“**源服务器（Source）**”；
  - 支持“**一键为所有其他区服批量映射**”，无需记忆繁杂的 Android 包名。
- 🛡️ **权限沙箱智能修复**：自动识别各区服客户端的专属 UID/GID，修正 Linux 权限，完美突破 Android 11/12/15 的 Scoped Storage 分区存储限制。
- 🌐 **多区服差异化安全处理**：
  - **国内渠道服（小米/vivo/华为/九游/应用宝等）**：与官方版本完全同源，**100% 互通**，校验表一并同步，进入游戏 **0 下载秒进**。
  - **外服（日服/美服/台服等）**：自动保留外服特有的版本校验，共享全球通用的全角色语音包（CV 占 10GB+）、后宅家具、战斗音效与骨骼（复用率 ~80%），仅需增量下载少量特有立绘与外语文本。

## 🛠️ 使用步骤

### 方式一：极速双击运行（推荐 Windows 用户）

1. **安装目标服**：  
   在 MuMu 模拟器中安装好您想玩的新区服客户端（例如小米服、vivo服、九游服或日服）。  
   *(建议初次安装后先点击打开一次游戏，停在开始下载资源的提示界面，然后彻底退出游戏)*
2. **启动工具**：  
   保持 MuMu 模拟器开启，双击本项目根目录下的 **`一键运行.bat`**。
3. **按提示交互**：  
   - 脚本会自动检测 MuMu 模拟器并连接；
   - 自动找到已拥有 29GB 资源的源客户端；
   - 列出所有检测到的新区服，您可以直接选择 **`[A] 一键同步到所有其他已安装区服`**，或选择指定区服；
   - 模式默认选择 `1`（硬链接模式，零额外空间占用，数秒完成）。
4. **启动畅玩**：  
   完成提示后，在模拟器中启动新安装的区服，即可直接进入游戏！

### 方式二：PowerShell 终端执行

打开 PowerShell 终端，执行：
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\sync_assets.ps1
```

## 🧠 技术原理解析

### 1. 为什么能跨服复用？
碧蓝航线客户端基于 Unity 引擎开发，核心数据（舰娘全量日语 CV 配音、Live2D 骨骼模型、后宅家具、战斗特效、背景音乐等）被打包成标准化 AssetBundles 存放于：
`/sdcard/Android/data/<包名>/files/AssetBundles/`
其中全角色的日语配音包体积超过 10GB，且全球各服完全一致；国内所有渠道服的资源包与校验清单更是一模一样。

### 2. 为什么能“零硬盘占用”？
Linux ext4 提供了底层 **硬链接（Hard Link）** 功能：
```bash
cp -al /data/media/0/Android/data/<源包名>/files/AssetBundles /data/media/0/Android/data/<目标包名>/files/
```
硬链接并不是复制文件，而是在文件系统中创建新的目录项，直接指向同一个磁盘数据 Inode 节点。无论挂载多少个区服，物理磁盘上始终只存在一份 29GB 的数据实体。

### 3. 如何解决 Android 12/15 的权限问题？
Android 11+ 引入了严格的 Scoped Storage（分区存储隔离），应用 A 无法跨包访问应用 B 的目录。
本工具通过 MuMu 的 ADB Root 权限，自动获取目标应用唯一的 Linux UID（如 `u0_a52`），将目标目录的归属设定为该 UID，并赋予 `chmod -R 777` 读写权限，使得各客户端均可无缝读取共享的资产块。

## ❓ 常见问题 (FAQ)

详细问答请参阅 [docs/FAQ.md](docs/FAQ.md)。

- **Q: 游戏未来更新大版本维护时会怎样？**  
  A: 各区服依然能正常通过应用内热更新。当某区服更新某个同名文件时，Unity 下载器通常会先写入临时文件后执行原子替换，更新该文件的硬链接会自动解除并指向新文件，互不影响。
- **Q: 是否会导致封号？**  
  A: 完全不会。本工具仅在操作系统文件层面同步合法的官方游戏资产（类似将游戏离线数据包放入指定文件夹），未对游戏客户端代码（libil2cpp 等）或通信协议做任何修改，属于 100% 原生官方资源。
